Como funciona o gate

O Policy Gate é o último job de cada scan. Ele:

  1. Coleta os SARIFs de Semgrep, Trivy e Gitleaks
  2. Remove findings do allowlist (falsos positivos)
  3. Compara com os limites definidos aqui
  4. Retorna exit 1 se houver violações — bloqueando o merge

Ao salvar, clique em Commit & Push para que os próximos scans usem a nova política.
